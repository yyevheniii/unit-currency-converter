| Місце | Код | Дані користувача чи API | Висновок |

| script.js, рядок 44 | `listContainer.innerHTML = ''` | ні | безпечно: лише очищення |

Увесь динамічний текст виводиться через `textContent` або інтерполяцію Vue (`{{ }}`), які не виконують HTML.
Текст помилки сервера на сторінку не виводиться: клієнт показує власні фіксовані повідомлення.

### 2. Демонстрація XSS «до» і «після»

Реальної вразливості в застосунку не знайдено. Для демонстрації навмисно відтворили небезпечний патерн:
у відповідь сервера (`base`) тимчасово записали рядок `<img src=x onerror="alert('XSS')">`,
а на клієнті вивели його через `innerHTML`. Результат: з'явилося вікно alert, тобто рядок виконався як HTML.

Виправлення: `ratesInfo.textContent = ...` замість `ratesInfo.innerHTML = ...`.
Після виправлення той самий рядок відображається як звичайний текст, alert не спрацьовує.
Тимчасові зміни прибрано, у фінальному коді використовується `textContent`.

### 3. localStorage / IndexedDB

У localStorage зберігається лише службовий прапорець `migrated`. В IndexedDB (`ConverterDB`, сховище `history`)
зберігаються коди валют, сума, результат і час конвертації. Паролів, токенів і персональних даних немає,
зайвої чутливої інформації не знайдено.

### 4. Секрети в коді

Реальних ключів і паролів у коді немає. Зовнішні адреси: власний `/api/rates` і публічна бібліотека Vue з CDN.

### 5. HTTPS

Застосунок має серверну частину на Node.js, тому для публікації обрано хмарний хостинг з підтримкою бекенду
(Render або Railway), який віддає сайт по HTTPS за замовчуванням. Локально на localhost HTTPS не потрібен.
